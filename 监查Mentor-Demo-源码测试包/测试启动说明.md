# 监查 Mentor Demo 测试说明

这是用于功能体验的本地 Demo，不连接真实大模型、CTMS/eTMF 或生产数据。

## 运行环境

- Windows 10/11
- Python 3.10 或更高版本（安装时勾选 **Add Python to PATH**）
- Node.js 20 LTS 或更高版本（自带 npm）
- 首次启动需要能够访问 pip 和 npm 的依赖下载源

## 启动

1. 解压压缩包。
2. 在解压后的目录空白处右键，选择“在终端中打开”。
3. 运行：

```powershell
.\start-for-tester.ps1
```

4. 如果 Windows 阻止脚本执行，可在同一目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start-for-tester.ps1
```

5. 看到“监查 Mentor Demo 已启动”后，在浏览器打开 `http://127.0.0.1:5173`。

首次启动会创建本地 Python 环境、下载依赖，并初始化一套脱敏的演示项目数据，耗时会比后续启动更长。

## 测试建议

- 以 CRA 角色进入“监查工作台”，录入碎片化自然语言记录，观察系统的本地结构化建议与待确认项。
- 在“模板库”查看或上传 `.docx` 监查报告模板，再创建 IMV 和任务清单。
- 在“报告生成”完成预检并导出可编辑 Word 报告。
- 需要回到初始演示数据时，可使用系统内的“恢复演示初始状态”。

## 本地数据范围

本包不包含开发者电脑上的数据库、上传附件、历史导出报告、前端依赖或 Python 虚拟环境。测试者的操作数据仅保存在自己解压目录下的本地 Demo 数据库中。
