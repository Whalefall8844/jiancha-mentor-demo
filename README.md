# 监查 Mentor · 临床试验监查报告 Agent Demo

这是一个面向国内临床试验监查工作流的本地可运行 Demo。它以 CRA 为报告事实、确认与提交责任人，PM/LM 仅承担后续审核职责；QA/临床运营承担规则、模板和已批准报告作废等受控操作。

当前版本使用本地确定性整理器模拟 AI 的结构化建议和专业语言优化。它不调用外部大模型，也不会把试验数据发送到外部服务。

## 启动

在 PowerShell 中进入本目录后运行：

```powershell
.\start-demo.ps1
```

脚本会准备本地 Python 环境和前端依赖，并启动：

- 前端：`http://127.0.0.1:5173`
- 后端：`http://127.0.0.1:8000`

若本机已有运行中的服务，请优先使用当前浏览器中的本地地址，避免重复启动多个后端进程。

## 可演示主链

1. 在“项目组合”由项目管理员建立项目级 MVP／盲态适用性评估，提交给 QA／临床运营审批；已审批且在实际活动结束日有效的结论会随新访视冻结。当前先提供台账与快照，资格门禁将在交互确认后接入。
2. 在“项目概览”维护项目、中心、受试者编号清单和访视；访视会冻结中心资料、受控文件、模板和规则包快照。CRA 可预览固定资料差异，选择性采纳新版来源，或填写原因撤销最近一次采纳。
3. 在“模板库”上传可编辑 `.docx` 模板，识别表格、标签相邻的固定资料填写位置和任务映射；管理员确认并通过 QA/临床运营审批后启用。
   已启用或已停用模板可直接创建修订草稿，复用其 Word 引用、映射与填写位；修订草稿可替换新版 Word 并重新识别，再复核后提交审批。
   草稿模板可将高置信度固定资料填写位建议批量导入为可编辑配置，已有人工填写位不会被覆盖。
   草稿模板也可批量带入高置信度的表级监查任务／报告区域映射，已有管理员配置不会被覆盖。
4. CRA 创建 IMV，系统按模板、规则包和历史未关闭行动项生成监查任务清单。
5. CRA 可在“监查工作台”持续记录碎片化自然语言；系统先保存工作底稿，后台再结合当前冻结模板的任务映射生成本地结构化建议，整理期间仍可继续输入。CRA 可在确认前重新指定目标区域，并可接受、修改、拒绝、补录或撤销记录。
6. 通过“澄清清单”处理缺失字段、受控文件版本、日期/规则适用期和行动项关闭依据等冲突；未解决的关键问题会进入报告预检阻断项。
7. 在“行动项”创建、关联多个发现、持续跟进、关闭或重新打开行动项，并留存关闭说明和脱敏附件；CRA 可发起紧急人工升级，PM/LM 可接收和完成处置。
8. 在“语言优化”查看原文、优化建议与差异；CRA 可采用、按修改稿采用、不采用，或对已采用稿填写原因后撤销并恢复原文。受试者、日期、数量、版本、否定关系和医学术语不会被自动改写为新事实。
9. 在“报告生成”执行完整性预检并生成真实可编辑 Word 修订版本。UA007-GT02 样例模板继续按原始 15 张表专用路径导出；其他模板按管理员已确认的填写位回填，无论表格数量是多少。
10. CRA 勾选确认声明后提交。PM/LM 需先领取审核，再提出定位建议、退回或批准；CRA 负责处置每条审核建议。QA/临床运营可对已批准版本作废，并自动创建关联工作草稿供 CRA 重新核对和提交。
11. CRA 可在项目台账中取消尚未形成正式报告的误建草稿访视，必须说明原因；原始工作底稿、附件和审计事件保留，已取消访视不再进入正常报告工作区。
12. 在“连续工作与协作中心”查看离线草稿、同步冲突、CRA 交接、提醒、升级和可展开的审计时间线；在报告页可导出审计 CSV 和系统外归档交接包。

## 演示角色

| 角色 | 核心职责 |
| --- | --- |
| CRA | 记录、确认事实、维护行动项、生成并提交报告、处置审核建议。 |
| PM / LM | 领取审核、提出建议、退回或批准；不直接修改 CRA 已提交事实。 |
| 项目管理员 | 管理项目成员、项目和中心范围内的基础配置，并发起/提交项目适用性评估。 |
| QA / 临床运营审批人 | 审批模板/规则配置和项目适用性评估，并对已批准报告执行受控作废。 |

角色切换仅用于本地 Demo 演示，不等同于生产身份认证、电子签名或客户正式授权。

## 当前边界

- 已覆盖：多项目/中心/访视、项目适用性评估台账与访视快照、模板匹配与映射、受控文件版本、Excel/CSV 导入、碎片化输入、离线草稿、冲突澄清、行动项与附件、真实 Word 导出、提交审核、版本链、审计导出和协作闭环。
- 未接入：真实外部大模型、电子签名、真实 CTMS/eTMF、SSO/MFA、生产级审计不可篡改存储和外部正式通知渠道。
- 本地 Demo 中不得输入直接身份信息、病历/源文件或非盲数据。

## 验收提示

“恢复演示初始状态”会重置本地 Demo 数据，仅适合演示环境。运行新功能后，请先确认交互是否符合业务预期；随后再统一执行浏览器、API、Word 和回归验收。
